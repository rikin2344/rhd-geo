# Upload to FTP - RHD Bearings Pages

## Overview
This document provides instructions for uploading bearing pages to the RHD Bearings server via FTP. This method bypasses WordPress entirely, ensuring perfect CSS styling and functionality.

## Prerequisites

### Required Files
- Complete HTML files (generated by the bearing page scripts)
- FTP credentials configured in `.env` file

### FTP Configuration
Add these credentials to your `.env` file:
```bash
FTP_HOST=ftp.rhdbearings.com
FTP_PORT=21
FTP_USERNAME=rikin@rhdbearings.com
FTP_PASSWORD="Rikin@@2025##"
FTP_ROOT_PATH=/public_html
```

## Automated Upload

### Using the Upload Script
The project includes `direct_cpanel_upload.py` for automated uploads:

```bash
python3 direct_cpanel_upload.py
```

### What the Script Does
1. **Connects to FTP server** using credentials from `.env`
2. **Navigates to WordPress root** (`/public_html`)
3. **Uploads HTML file** to server
4. **Verifies upload** by checking file size
5. **Provides direct URL** for immediate access


## Manual Upload Methods

### Method 1: cPanel File Manager
1. **Login to cPanel** with your hosting credentials
2. **Open File Manager**
3. **Navigate to `public_html`**
4. **Click "Upload"**
5. **Select your HTML file**
6. **Wait for upload to complete**
7. **Access via direct URL**

### Method 2: FTP Client (FileZilla, etc.)
1. **Open your FTP client**
2. **Connect using credentials:**
   - Host: `ftp.rhdbearings.com`
   - Username: `rikin@rhdbearings.com`
   - Password: `Rikin@@2025##`
   - Port: `21`
3. **Navigate to `/public_html`**
4. **Upload HTML file**
5. **Access via direct URL**

### Method 3: WordPress Media Library
1. **WordPress Admin → Media → Add New**
2. **Upload HTML file**
3. **Get direct URL from media library**
4. **Access uploaded file directly**

## Troubleshooting

### Common Issues

#### FTP Connection Failed
- **Check credentials** in `.env` file
- **Verify FTP host** (try `rhdbearings.com` if `ftp.rhdbearings.com` fails)
- **Check firewall** settings

#### File Not Uploading
- **Check file permissions** on local file
- **Verify disk space** on server
- **Try smaller file** to test connection

#### Page Not Loading
- **Check file path** - ensure uploaded to `/public_html`
- **Verify file name** - no special characters or spaces
- **Clear browser cache** and try again

### Support Commands
```bash
# Test FTP connection
python3 -c "import ftplib; ftp=ftplib.FTP('ftp.rhdbearings.com'); ftp.login('rikin@rhdbearings.com', 'Rikin@@2025##'); print('✅ Connection successful')"

curl -I https://rhdbearings.com/miniature-bearings.html
```

## Security Notes

### Credentials Management
- **Never commit** `.env` file to version control
- **Use strong passwords** for FTP access
- **Regularly rotate** FTP credentials
- **Limit FTP access** to necessary IP addresses only

### File Security
- **Validate HTML content** before upload
- **Scan for malicious code** in generated files
- **Use HTTPS** for all page access
- **Monitor server logs** for unusual activity

## Performance Optimization

### File Size Management
- **Optimize images** before embedding as base64
- **Minify CSS/JS** in production builds
- **Compress HTML** where possible
- **Monitor page load times**

### Caching Strategy
- **Enable server-side caching** for static HTML files
- **Use CDN** for global distribution if needed
- **Set proper cache headers** for optimal performance
